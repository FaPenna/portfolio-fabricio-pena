Trabalhos & Dashboards

Uma seleção de sites, aplicações e painéis de Business Intelligence que desenvolvi. Clique em qualquer card para acessar o projeto.

🌐 Web App
Portal Analítico de Admissões

Aplicação própria de BI para RH que centraliza todo o processo de admissão de colaboradores num único painel: KPIs, funil de admissão, SLA por empresa/responsável/centro de custo, alertas automáticos de pendências e ranking de performance da equipe. Resolve o problema de acompanhar admissões espalhadas em várias planilhas, dando visão executiva em tempo real. Construída 100% no front-end — sem servidor ou banco de dados: os dados são importados de uma planilha Excel (via SheetJS), processados e visualizados com Chart.js e DataTables, e é possível exportar um novo .html autocontido já com a base atualizada embutida, funcionando como um "banco de dados" portátil e offline.

🔒 Dados fictícios — nomes, empresas e valores exibidos foram gerados apenas para fins de demonstração, sem nenhuma informação real de empresas ou pessoas.
JavaScript Chart.js SheetJS (Excel) DataTables Tailwind CSS
🌐 Web App
Painel de Desligamentos & Rescisões

Painel de BI para RH que consolida os desligamentos de vários meses (cada um em uma aba separada da planilha, com layouts levemente diferentes entre si) em uma visão única e padronizada: KPIs por tipo de desligamento, custo financeiro (verbas, FGTS, IRRF), SLA de homologação com alertas automáticos de prazos vencidos ou perto de vencer, e uma tabela detalhada com filtros e exportação. Resolve o problema de acompanhar rescisões e prazos legais espalhados em planilhas mensais soltas, normalizando colunas com nomes e formatos diferentes de mês para mês. Assim como o Portal de Admissões, é 100% front-end: os dados são importados de uma planilha Excel (via SheetJS), processados e visualizados com Chart.js e DataTables, com opção de gerar um novo .html autocontido já com a base atualizada embutida.

🔒 Dados fictícios — nomes, empresas e valores exibidos foram gerados apenas para fins de demonstração, sem nenhuma informação real de empresas ou pessoas.
JavaScript Chart.js SheetJS (Excel) DataTables Tailwind CSS
🌐 Web App
Painel de Gestão de Pessoas

O mais completo dos três: um BI de workforce management multiunidade e multiestado para um contrato de atendimento ao cidadão terceirizado. Cruza o quadro contratado (CET) com o efetivo real por posto e unidade, mostrando onde há déficit ou sobra de pessoal e o impacto financeiro disso; acompanha a cota de PCD exigida por lei frente à realidade de cada filial; analisa turnover por causa e por unidade; traz a relação nominal por cargo com ponto eletrônico e afastamentos; e gerencia o programa de jovem aprendiz — tudo em um único painel executivo. Resolve o problema de decidir onde redistribuir pessoal entre unidades com overhead e unidades com déficit sem custo adicional de contrato. Diferente dos outros dois projetos, é 100% vanilla: nenhuma biblioteca externa, nem para os gráficos (feitos à mão em Canvas API) — só HTML, CSS e JavaScript puro em um único arquivo autocontido.

🔒 Dados fictícios — nomes, empresas e valores exibidos foram gerados apenas para fins de demonstração, sem nenhuma informação real de empresas ou pessoas.
JavaScript Canvas API HTML5 / CSS3 Data Visualization
🌐 Web App
Dashboard de Atestados & Absenteísmo

Painel de BI de RH focado em absenteísmo: para cada colaborador, cruza quantidade de atestados, dias perdidos e reincidência nos últimos 3 meses, sinalizando automaticamente quem está em padrão de atestados recorrentes e precisa de atenção do RH — antes que isso apareça como um problema maior de turnover ou produtividade. Traz rankings por unidade e departamento, tabela geral com filtros (por clique nos próprios gráficos, com breadcrumb de navegação) e exportação em CSV/Excel/impressão. A base pode ser atualizada com uma nova planilha diretamente pelo navegador — fica salva localmente (localStorage) e é possível gerar um novo .html autocontido já com os dados atualizados embutidos, sem precisar de nenhum backend.

🔒 Dados fictícios — nomes, empresas e valores exibidos foram gerados apenas para fins de demonstração, sem nenhuma informação real de empresas ou pessoas.
JavaScript Chart.js SheetJS (Excel) CSS custom
